# Saper

Konsolowa implementacja klasycznej gry logicznej **Saper** napisana w języku C++. Projekt skupia się na implementacji logiki gry, operacjach na tablicach wielowymiarowych oraz obsłudze wejścia/wyjścia w środowisku konsolowym.

## 🎮 O projekcie
Gracz ma za zadanie odkryć wszystkie bezpieczne pola na planszy, unikając detonacji ukrytych min. Rozgrywka w całości toczy się w oknie terminala.

## ✨ Funkcjonalności
- Losowe generowanie min na planszy
- Dynamiczne przeliczanie sąsiadujących pól z minami
- Odkrywanie pól oraz oznaczanie potencjalnych min flagami
- Detekcja wygranej oraz przegranej
- Zapis/odczyt danych stanu gry przy użyciu zewnętrznego pliku tekstowego (`plik.txt`)

## 🛠️ Technologie i narzędzia
- **Język:** C++
- **Środowisko:** Visual Studio
- **Interfejs:** Konsola
